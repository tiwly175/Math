⚠️ ความปลอดภัย (อ่านก่อนใช้งาน)
  • แอปพลิเคชันนี้ ทำงานออฟไลน์ 100% (หลังโหลดครั้งแรก)
  • ไม่มีการเก็บข้อมูลส่วนตัว เช่น ชื่อ อีเมล หรือ IP Address และไม่มีสคริปต์ติดตาม (analytics) ใดๆ ทั้งสิ้น
  • ข้อมูลความคืบหน้าจะถูกบันทึกไว้ใน Local Storage ของเบราว์เซอร์ของคุณเท่านั้น
  • ไม่มีระบบส่งข้อมูลไปยังเซิร์ฟเวอร์ใดๆ ทั้งสิ้น (ดูได้จาก Source Code ว่าไม่มีคำสั่ง fetch หรือ XMLHttpRequest)
  • เปิดได้ทุกเบราว์เซอร์ ไม่ต้องติดตั้งซอฟต์แวร์เพิ่ม
